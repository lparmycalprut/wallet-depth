CHECKLIST URUTAN FILTER SCAN BEST POOL METEORA 24H
==================================================

Gunakan urutan ini untuk setiap pool. Jika satu filter gagal, pool
langsung gugur dan tidak lanjut ke enrichment berikutnya.

FILTER AWAL (sumber listing)
----------------------------
[ ] 1. Pool adalah tipe DLMM.
[ ] 2. Timeframe yang dipakai adalah 24H.
[ ] 3. Active TVL >= $50,000.

FILTER PER POOL
---------------
[ ] 4. Data fee dan volatility tersedia, finite, dan tidak negatif.
[ ] 5. Volatility bukan 0.
[ ] 6. Jumlah LPs >= 100.
[ ] 7. Volatility berada pada rentang 1% sampai 10% (inklusif).
[ ] 8. F/V >= 3x.
[ ] 9. Fee/TVL >= 30%.
[ ] 10. Top-10 supply concentration < 20%.

INFORMASI TOKEN:SOL (BUKAN FILTER)
----------------------------------
[ ] 11. Ambil detail pool dari API resmi Meteora bila tersedia.
[ ] 12. Hitung nilai USD masing-masing sisi: jumlah token x harga USD.
[ ] 13. Tampilkan rasio Token:SOL pada pool lolos dan pool dilewati.

Rasio apa pun tidak menggugurkan pool. API detail gagal/non-SOL/tidak valid
hanya membuat kolom Token:SOL menampilkan tanda —.

FILTER TERAKHIR: RISIKO GMGN
----------------------------
[ ] 14. Baca top_bundler_trader_percentage.
[ ] 15. Baca top_entrapment_trader_percentage (phishing/entrapment).
[ ] 16. Hitung Bundler + Phishing.
[ ] 17. Pastikan hasil gabungan <= 25%.

HASIL AKHIR
-----------
[ ] LOLOS jika pool melewati filter listing dan Bundler+Phishing <= 25%.
[ ] Tepat 25% = LOLOS.
[ ] GAGAL/DILEWATI jika gabungan > 25% atau salah satu field risiko GMGN
    tidak tersedia/tidak valid.
