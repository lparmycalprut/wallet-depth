CHECKLIST URUTAN FILTER SCAN BEST POOL METEORA 24H
==================================================

Gunakan urutan ini untuk setiap pool. Pool yang gagal keras dibuang total;
pool yang hanya gagal ambang tampil F/V (tetapi masih F/V >= 5x) masuk tabel
"pool dilewati" dan tetap mendapat data informasi yang relevan.

FILTER AWAL (sumber listing)
----------------------------
[ ] 1. Pool adalah tipe DLMM.
[ ] 2. Timeframe yang dipakai adalah 24H.
[ ] 3. Active TVL >= $50,000.

FILTER PER POOL
---------------
[ ] 4. Data fee dan volatility tersedia, finite, dan tidak negatif.
[ ] 5. Volatility bukan 0.
[ ] 6. Jumlah LPs >= 100.
[ ] 7. Volatility berada pada rentang 1% sampai 10% (inklusif).
[ ] 8. F/V >= 5x untuk masuk kandidat Best Pool.
[ ] 9. F/V >= 10x untuk tampil di tabel utama; F/V 5x sampai <10x masuk
       "pool dilewati".
[ ] 10. Tampilkan Fee/TVL sebagai informasi (bukan filter).
[ ] 11. Top-10 supply concentration < 25%.

INFORMASI TOKEN:SOL (BUKAN FILTER)
----------------------------------
[ ] 12. Ambil detail pool dari API resmi Meteora bila tersedia.
[ ] 13. Hitung nilai USD masing-masing sisi: jumlah token x harga USD.
[ ] 14. Tampilkan rasio Token:SOL pada pool lolos dan pool dilewati.

Rasio apa pun tidak menggugurkan pool. API detail gagal/non-SOL/tidak valid
hanya membuat kolom Token:SOL menampilkan tanda —.

INFORMASI RISIKO GMGN — BUKAN FILTER
-----------------------------------
[ ] 15. Untuk pool lolos dan pool dilewati yang masih memenuhi F/V >= 5x,
       ambil top_bundler_trader_percentage bila tersedia.
[ ] 16. Ambil top_entrapment_trader_percentage (phishing/entrapment) bila tersedia.
[ ] 17. Hitung dan tampilkan Bundler + Phishing sebagai informasi; laporan
       gagal dibaca cukup menampilkan —.
[ ] 18. Nilai Bundler+Phishing tinggi boleh diberi penanda visual risiko,
       tetapi tidak pernah memindahkan atau menggugurkan pool.

HASIL AKHIR
-----------
[ ] LOLOS jika pool melewati filter listing utama termasuk F/V >= 10x;
    nilai Bundler+Phishing tinggi atau tidak terbaca tidak mengubah hasil.
[ ] DILEWATI jika F/V 5x sampai <10x atau ada gap pool non-hard lain.
[ ] DIBUANG TOTAL jika F/V < 5x/tidak valid, LPs gagal, volatility gagal,
    atau Top10 >= 25%.
